Build your own ServMod Box

The ServMod Box is a small ESP32-S3 unit that links your phone to a drive, PLC or CAN bus wirelessly. For ServMod Pro owners we publish the wiring drawings and the ready-to-flash firmware, so you can build one yourself.

Source code is not published, only the compiled firmware. You build the hardware, flash it from your phone with the ESP32 Loader inside the ServMod app, and the Box then talks to the app over Wi-Fi or Bluetooth LE. Firmware is not updated over the air: you flash a new file with a cable.

1. Wiring drawings

All signals are 3.3 V logic. Check the notes at the bottom of each drawing. Tap a drawing to open it full size.

2. Firmware

For a first install or any update, take the full image for your board. The application only file is for updating a board that already runs a 0.9.x Box. Flashing replaces the settings stored in the Box.

3. Flash it from your phone

  1. Download the .bin file to the phone (it lands in Downloads).
  2. Connect the board to the phone with a USB cable and an OTG adapter. DevKit: use the board's COM port. Mini: the USB-C port.
  3. Open ServMod > ESP32 Loader and choose chip ESP32-S3. Flash size: 16 MB for the DevKit, 4 MB for the mini.
  4. Tap + ADD, pick the file, and set the offset: 0x0 for the full image, 0x10000 for application only.
  5. Tap FLASH. The board restarts by itself when it is done.

If the board does not enter download mode by itself, hold BOOT, tap RESET, release BOOT, and then connect. After flashing, open ServMod and connect to the Box: the app shows its firmware version.

Updating later

When a new firmware is published, this page shows the new version. Repeat the flashing steps above with the new file. Compare the SHA-256 shown next to each file if you want to check the download.

Honest status: the DevKit Box firmware 0.9.1 was flashed from a phone and started. The mini build is experimental and has not been flashed on a board yet. Building and using hardware is at your own risk, see the terms.
