A job, from the cable to the checked write

The screens are the same for every supported drive, so you learn the routine once.

  1. Connect

    Plug the USB-RS485 adapter into the phone and wire A and B to the drive. ServMod finds the adapter and asks for permission once.

  2. Back up

    Read every parameter and save the backup on the phone. You can share it as a file or keep it as the reference for the machine.

  3. Compare

    Set any backup against the drive, or the drive against factory settings, and see only what differs.

  4. Write and check

    Change a value, write it, and read the drive again before you leave the machine.

Module details

Careful by design

Nothing leaves the phone

Backups, printer lists, notes and passwords stay on the device. The only network request the app makes by itself is the check for a new version.

The PLC module only reads

It has no write function at all, so you can look at a running controller without risking a change.

Passwords stay encrypted

The Access vault uses AES-GCM through the Android keystore, hides itself from screenshots, and clears the clipboard after 30 seconds.

Manual names, not nicknames

Parameters keep the codes and names from the manufacturer's manual, so what you read on screen matches the paper.

Made on the shop floor
