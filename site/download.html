What the free version does

Reads and saves drive parameters, compares a backup with a drive, shows faults, and has the cable and wiring cheat sheets. Writing parameters back, restore and manual control are in Pro or Subscription, which you buy inside the app. Plans and prices.

Install in four steps

You will see two or three warnings from Android. They appear for every app installed outside Google Play. If you already downloaded this file before, Chrome may also ask "Download file again?"; tap Download again.

  1. Tap Download free version and wait for the file (about 22 MB). Chrome warns that an APK file might be harmful. This is normal for any app that is not from Google Play: tap Download anyway.
  2. Tap Open on the "File downloaded" message (or open it from Downloads). If Android asks, allow your browser or Files app to install apps from this source, then tap Install.
  3. Google Play Protect says the app is unknown, because it is not on Google Play yet. Choose Send this time or Don't send; both continue the installation. If it blocks the install, choose More details, then Install anyway.
  4. Open ServMod, read the terms and start. Plug in your OTG adapter and cable when you reach a drive.
