What the free version does

Reads and saves drive parameters, compares a backup with a drive, shows faults, and has the cable and wiring cheat sheets. Writing parameters back, restore and manual control are in Pro or Subscription, which you buy inside the app. Plans and prices.

How to install

Android shows a few warnings, because ServMod is not on Google Play yet. They appear for every app installed from outside the store. In every screenshot below, the orange frame marks what to tap.

  1. 1

    Download the file

    Tap Download free version and wait for the file (about 22 MB). Chrome says the file might be harmful, as it does for every APK. Tap Download anyway. If you downloaded it before, Chrome asks "Download file again?": tap Download again.

  2. 2

    Open the file

    When the download finishes, tap Open on the "File downloaded" message. You can also open the file from your Downloads folder. If Android asks, allow your browser or Files app to install apps from this source.

  3. 3

    Tap Install

    Android asks "Do you want to install this app?". Tap Install.

  4. 4

    Play Protect: continue the installation

    Google Play Protect has not seen the app before, so it asks about a security check. Your phone shows one of these two screens. On the first, tap Send this time (or Don't send). On the second, tap More details, then Install without scanning. Scanning the app (Scan app) also works. Do not tap Don't install app.

  5. 5

    Open ServMod and accept the terms

    Tap Open when the installation is done. Read the terms, tick the box and tap Accept and continue.

  6. 6

    Start using it

    You land on the home screen with all the tools. The FREE label shows that no code is needed. Plug in your OTG adapter and cable when you reach a drive.
