Requests

Tell us which drive, protocol or feature you need. We read the requests and use them to decide what ServMod learns next. A request is not a promise that a model will be added.

Only if you want a reply or to hear when it is added. We do not add you to any list.

Helpful to include

  • The exact model and series, for example VLT FC 280 rather than only Danfoss.
  • The port you use: RS-485 terminals, RJ45, USB, CAN.
  • A link to the communication manual, if you have one.
  • Whether you need to read parameters, write them, run the drive or read faults.
