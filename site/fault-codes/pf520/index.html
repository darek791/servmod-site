Fault codes / Allen-Bradley PowerFlex 525

Allen-Bradley PowerFlex 525 fault codes: meaning and checks

47 fault and warning codes of the Allen-Bradley PowerFlex 525, each with what it means and what to check first. Tap a code for the full checklist.

CodeNameMeaning
F002Auxiliary inputAn external trip signal wired to a digital input set as Aux Fault has opened, so the drive stopped on purpose.
F003Power lossThe drive saw a single-phase supply condition while carrying a heavy load.
F004UndervoltageThe DC bus fell below its minimum level, usually because the supply sagged or dropped out.
F005OvervoltageThe DC bus rose above its maximum level, from a high supply, line transients or motor regeneration.
F006Motor stalledThe drive could not accelerate or decelerate the motor, typically because it sat in current limit too long.
F007Motor overloadThe internal electronic overload protection tripped because the motor drew excessive current for too long.
F008Heatsink overtemperatureThe heatsink/power module temperature exceeded its limit.
F009Control module overtemperatureThe control module temperature exceeded its limit.
F012Hardware overcurrentDrive output current exceeded the hardware current limit.
F013Ground faultA current path to earth was detected at one or more drive output terminals.
F015Load lossOutput torque current stayed below the A490 level for longer than A491 time, so the load appears to be lost...
F021Output phase lossLoss of an output phase was detected (only when the function is enabled with A557).
F029Analog input lossAn analog input configured to fault on signal loss has lost its signal.
F033Auto restart tries exceededThe drive tried to reset a fault and resume running the number of times set in A541 and did not succeed.
F038Phase U to groundA ground fault was detected on motor phase U between the drive and the motor.
F039Phase V to groundA ground fault was detected on motor phase V between the drive and the motor.
F040Phase W to groundA ground fault was detected on motor phase W between the drive and the motor.
F041Phase UV shortExcessive current was detected between two output terminals (UV), indicating a short.
F042Phase UW shortExcessive current was detected between two output terminals (UW), indicating a short.
F043Phase VW shortExcessive current was detected between two output terminals (VW), indicating a short.
F048Parameters defaultedThe drive was told to write factory default values to EEPROM.
F059Safety openBoth safety inputs (Safety 1 and Safety 2) are de-energised, and t105 is set to fault in that state.
F063Software overcurrent (shear pin)Current stayed above the shear pin level (A486/A488) for longer than the shear pin time (A487/A489).
F064Drive overloadThe drive's own overload rating was exceeded.
F070Power unitA failure was detected in the drive power section.
F071DSI network lossControl over the Modbus/DSI (RS-485) link was interrupted.
F072Option card network lossControl through the remote network of the optional network card was interrupted.
F073Embedded EtherNet/IP network lossControl through the embedded EtherNet/IP adapter was interrupted.
F080Autotune failureThe autotune routine was cancelled by the user or did not complete successfully.
F081DSI communication lossCommunication between the drive and the Modbus/DSI master was interrupted.
F082Option card communication lossCommunication between the drive and the network option card was interrupted.
F083Embedded EtherNet/IP communication lossInternal communication between the drive and the embedded EtherNet/IP adapter was interrupted.
F091Encoder lossOne of the two encoder channel signals is missing (differential encoder required).
F094Function lossThe Freeze-Fire (Function Loss) input is inactive, i.e. the input to the programmed terminal is open.
F100Parameter checksum errorThe drive's non-volatile parameter storage is corrupted.
F101External storage errorExternal non-volatile storage has failed.
F105Control module connect errorThe control module was disconnected while the drive was powered.
F106Incompatible control/power moduleThe PowerFlex 525 control module does not support a power module with 0.25 HP rating.
F107Replaced control/power moduleThe control module could not recognise the power module (hardware failure).
F109Control/power module mismatchThe control module was mounted on a different drive type of power module.
F110Keypad membraneThe keypad membrane has failed or is disconnected.
F111Safety hardwareA malfunction in the safety input enable hardware; one of the safety inputs is not enabled.
F114Microprocessor failureMicroprocessor failure.
F122I/O board failureA failure was detected in the drive control and I/O section.
F125Flash update requiredThe drive firmware is corrupt, mismatched or incompatible with the hardware.
F126Non-recoverable errorA non-recoverable firmware or hardware error was detected; the drive stopped and reset itself.
F127DSI flash update requiredA critical firmware problem was detected and the drive is running backup firmware that supports only DSI...

Source: PowerFlex 520-series User Manual (520-UM001O-EN-E, September 2025). Manufacturer page. See also the Allen-Bradley PowerFlex 525 parameter list, the connection and backup page and the wiring diagrams.
