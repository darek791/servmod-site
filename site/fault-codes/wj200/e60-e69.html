Fault codes / Hitachi WJ200 / E60-E69

Hitachi WJ200 fault E60-E69: Option board error

The drive detected an error in the option board fitted in the option slot.

What to check

  1. Reseat the option board and check it is compatible
  2. See the option board's instruction manual for the specific code
  3. Check P001 for the action on option errors

Source: WJ200 Series Quick Reference Guide (NT3381AX, April 2016), page 99. Manufacturer page.
